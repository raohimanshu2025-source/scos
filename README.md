# 🏙️ Smart City Operating System (SCOS)

An interactive, multi-agency urban disaster response platform and spatial digital twin designed to monitor municipal infrastructure, detect secondary cascading failures, and automate emergency coordination across city departments.

## 📌 Overview

During severe urban emergencies (such as urban flooding, power grid trips, or water main ruptures), municipal response is often hindered by fragmented departmental communication and siloed data systems. 

The **Smart City Operating System (SCOS)** bridges this gap by unifying GIS spatial mapping, topological infrastructure dependency modeling, and automated Standard Operating Procedure (SOP) generation into a single real-time operations dashboard.

---

## ✨ Key Features

- 🗺️ **Urban Spatial Digital Twin**: Interactive multi-layer GIS mapping showing drainage canals, power substations, pumping stations, critical roads, and hospitals.
- ⚡ **Cascading Failure Detection**: Graph-based topological modeling that traces secondary dependencies (e.g., waterlogging → substation trip → pump shutdown → hospital road access cutoff).
- 📋 **Automated Multi-Agency SOP Synthesis**: Instant generation of tailored emergency action checklists and task routing for Municipal Corporations, Power Corporations (UPPCL), Traffic Police, and Disaster Management (NDMA/SDMA).
- ⏱️ **Decision Support & Triage**: Prioritized risk scoring, resource allocation recommendations, and incident timeline tracking.
- 🔒 **Cryptographic Governance Audit**: SHA-256 event chaining and immutable audit trails ensuring full traceability of every municipal action and decision.
- 📊 **Scenario Benchmark Engine**: Pre-calibrated disaster benchmarks (monsoon cloudburst, pump station failure, hospital corridor ingress, etc.) for operational evaluation.

---

## 🛠️ Tech Stack

- **Frontend / Framework**: React 18, TypeScript, Vite
- **Styling & UI**: Tailwind CSS, Lucide React Icons, Motion animations
- **Data Architecture & State**: Modular typed services, reactive in-memory stores, topological graph structures
- **Build Tooling**: Node.js, Vite
